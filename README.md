# Corekit — контрольная работа №3

Адаптивный учебный магазин техники на React. Проект продолжает КР №1 и выполняет первую часть КР №3 по ПЗ №12 на тему «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Запуск

В архиве с готовой версией откройте `Corekit.html` двойным щелчком. В файл включены сайт, изображения и заставка. Его можно использовать без сервера и интернета.

### Запуск исходников

Нужен Node.js 20.19+ или 22.12+.

    npm ci
    npm run dev

Открой адрес, который напечатает Vite. Для проверки собранной версии:

    npm run build
    npm run preview

Чтобы собрать новый файл для открытия двойным щелчком, выполните `npm run build:standalone`. Результат появится в `standalone/Corekit.html`.

Все страницы собираются в папку dist. У формы есть браузерная валидация и диалог с введёнными данными. Форма демонстрационная, данные остаются во вкладке.

## Практическая работа №12

- На всех HTML-входах задан viewport. Каждая страница подключает css/style.css, затем css/responsive.css, а также общий вход приложения React.
- Базовые стили раскладки рассчитаны на телефон. Медиазапросы min-width на 640, 768, 900, 1024 и 1280 px перестраивают сетки, навигацию, первый экран, фильтры и форму. Bootstrap не используется.
- На телефоне ссылки меню расположены под логотипом, а фильтры можно развернуть над товарами. С 1024 px фильтры располагаются сбоку.
- Веб-версия подбирает размеры изображений для плиток, карточек и галерей через `srcset` и `sizes`. Миниатюры галерей загружаются отдельными компактными файлами. Карточки используют отложенную загрузку фото.
- Поля формы имеют связанные подписи. На телефоне поля выстроены в одну колонку, на планшете и компьютере часть полей идёт в две.
- Таблица характеристик сохраняет заголовки столбцов и строк, а длинные значения переносятся внутри ячеек. Диалог заявки ограничен областью просмотра и закрывается кнопкой или клавишей Esc.
- На первом экране один раз проигрывается фоновая заставка с четырьмя цветами iPhone 18 Pro. Широкая версия использует 2560 × 1200 при 60 кадрах/с. Кадры сначала отрисованы в 3840 × 1800, чтобы улучшить детализацию камер и граней. Мобильная версия использует отдельное компактное кадрирование при той же частоте. Переход к крупному плану проходит через непрерывный разворот и приближение телефонов. При включённом сокращении движения или ошибке загрузки видео показывается статичный финальный кадр. Кнопка «Оформить заказ» открывает форму с выбранным iPhone.
- Геометрия, текстуры и материалы всех четырёх цветов взяты из [официальной AR-модели Apple](https://www.apple.com/105/media/us/iphone-18-pro/2026/591df885-5ee2-4173-86e6-401021249f7c/ar/iphone-18-pro-e-sim.usdz). Заставка предварительно отрисована. Характеристики взяты со [страницы Apple](https://www.apple.com/iphone-18-pro/specs/). Модель и товарные знаки Apple используются в демонстрации учебного магазина.

## Практические работы №13 и №14

- У значимых фотографий в галереях есть описания ракурсов. Декоративные изображения с соседними подписями используют пустой `alt`.
- Сетка категорий оформлена как навигация. Плашки товара находятся вне ссылки изображения. Подписи кнопок, состояния каруселей, сообщения фильтров и имя диалога доступны вспомогательным технологиям.
- В Chrome проверены семь маршрутов на размерах 320×740, 360×800, 390×844, 430×932, 768×1000, 844×390 и 1920×1080. Проверены раскрытие фильтров, ввод и ошибки формы, таблицы, работа помощника и закрытие диалогов с клавиатуры.
- При плотности 1x браузер выбирает фото BORK C781 шириной 400 px на телефоне и 800 px на рабочем столе. Миниатюры галереи имеют ширину 120 px.
- Результаты автоматической проверки доступны в [отчёте Lighthouse](reports/lighthouse-mobile.html).

## Практическая работа №15

Откройте главную страницу и консоль браузера. В ней выводится таблица с результатами функций из [`src/product-tools.js`](src/product-tools.js). Пример использует объект товара GTA VI со строковым названием, числовыми полями цены и процента скидки, логическим признаком наличия. Функции форматируют цену, рассчитывают скидку и итоговую цену, определяют статус и составляют описание. Скидка и наличие заданы для учебного примера в консоли.
