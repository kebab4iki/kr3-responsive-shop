# Corekit — контрольная работа №3

Адаптивный учебный магазин техники на React. Проект продолжает КР №1 и выполняет первую часть КР №3 по ПЗ №12 на тему «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Запуск

В архиве с готовой версией откройте `Corekit.html` двойным щелчком. В файл включены сайт, изображения и заставка. Его можно использовать без сервера и интернета.

### Запуск исходников

Нужен Node.js 20.19+ или 22.12+.

    npm ci
    npm run dev

Открой адрес, который напечатает Vite. Для проверки собранной версии:

    npm run build
    npm run preview

Чтобы собрать новый файл для открытия двойным щелчком, выполните `npm run build:standalone`. Результат появится в `standalone/Corekit.html`.

Все страницы собираются в папку dist. У формы есть браузерная валидация и диалог с введёнными данными. Форма демонстрационная, данные остаются во вкладке.

## Практическая работа №12

- На всех HTML-входах задан viewport. Каждая страница подключает css/style.css, затем css/responsive.css, а также общий вход приложения React.
- Базовые стили раскладки рассчитаны на телефон. Медиазапросы min-width на 640, 768, 900, 1024 и 1280 px перестраивают сетки, навигацию, первый экран, фильтры и форму. Bootstrap не используется.
- На телефоне все ссылки меню видны в колонке, а фильтр расположен над товарами. С 768 px шапка закрепляется сверху. С 1024 px фильтр располагается сбоку.
- Изображения ограничены шириной контейнера. В picture используются WebP-варианты, srcset и sizes. Фото карточек загружаются с loading="lazy".
- Поля формы имеют связанные подписи. На телефоне поля выстроены в одну колонку, на планшете и компьютере часть полей идёт в две.
- Таблица характеристик прокручивается внутри своего контейнера. Диалог ограничен размерами области просмотра и закрывается кнопкой или клавишей Esc.
- На первом экране один раз проигрывается фоновая заставка с четырьмя цветами iPhone 18 Pro. Широкая версия отрисована в 1920 × 900 при 60 кадрах/с. Мобильная версия использует отдельное компактное кадрирование при той же частоте. Переход к крупному плану проходит через непрерывный разворот и приближение телефонов. При включённом сокращении движения или ошибке загрузки видео показывается статичный финальный кадр. Кнопка «Оформить заказ» открывает форму с выбранным iPhone.
- Геометрия, текстуры и материалы всех четырёх цветов взяты из [официальной AR-модели Apple](https://www.apple.com/105/media/us/iphone-18-pro/2026/591df885-5ee2-4173-86e6-401021249f7c/ar/iphone-18-pro-e-sim.usdz). Заставка предварительно отрисована. Характеристики взяты со [страницы Apple](https://www.apple.com/iphone-18-pro/specs/). Модель и товарные знаки Apple используются в демонстрации учебного магазина.

## Проверка

В Chrome использованы эмуляция ширин и отслеживание запросов изображений через Chrome DevTools Protocol.

| Ширина | Шапка | Карточки на главной | Фильтр | Поля заявки |
| --- | --- | --- | --- | --- |
| 360 px | Ссылки в колонке | 1 колонка | Над товарами | 1 колонка |
| 430 px | Ссылки в колонке | 1 колонка | Над товарами | 1 колонка |
| 768 px | Закреплена, меню в строку | 2 колонки | Над товарами | 2 колонки |
| 1024 px | Закреплена, меню в строку | 3 колонки | Сбоку | 2 колонки |
| 1440 px | Закреплена, меню в строку | 3 колонки | Сбоку | 2 колонки |

На этих ширинах проверены главная, каталог, список товаров, категория, карточки товара, форма и контакты. Общей горизонтальной прокрутки нет. На телефоне таблица прокручивается отдельно. При плотности экрана 1x на 360 px выбран постер 360w, на 1440 px — 1280w. Изображение колонок на 360 px запрашивается после прокрутки к карточке.
