# «Project shop: учебный сайт техники»

Простой учебный сайт интернет-магазина для практических занятий №1–8 по фронтенд-разработке.

**Студент:** [Кудряшов Максим Валентинович]  
**Группа:** [ЭФБО-14-25]  
**Дисциплина:** Фронтенд и бэкенд разработка

**Ссылка на опубликованный проект :** https://kebab4iki.github.io/kebab4iki-kr1-html-css-shop/

## Страницы
- `index.html` — главная, 6 популярных товаров.
- `catalog.html` — каталог категорий товаров.
- `products.html` — отдельный список всех 12 товаров с описаниями и ценами.
- `application.html` — форма заявки с HTML-валидацией и демонстрационным диалогом.
- `contacts.html` — контактная информация.

## Технологии
HTML5, CSS3 (переменные, Flexbox, Grid, БЭМ), JavaScript без библиотек.
